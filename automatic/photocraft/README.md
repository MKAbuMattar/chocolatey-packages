# PhotoCraft Chocolatey Package

## What is PhotoCraft?

PhotoCraft is an open-source image editor written entirely in Rust: layers, masks,
adjustment layers, layer styles, type, vectors and brushes, and it opens, edits and
saves layered PSD files. Its menus, shortcuts and panels follow the layout Photoshop
users already know. It runs natively on a GPU compositor and works offline.

## Usage

The package installs the PhotoCraft desktop app. Start it from the Start Menu. See
[PhotoCraft on getartcraft.com](https://getartcraft.com/apps/photocraft) for more.
