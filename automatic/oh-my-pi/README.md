# Oh My Pi Chocolatey Package

## What is Oh My Pi?

Oh My Pi is a coding agent for the terminal with the IDE wired in: it drives language
servers and debuggers alongside the model, and works with more than 60 model providers.
It is a fork of Pi by Mario Zechner, built by Stencil Labs.

## Usage

The package installs the `omp` command. Open a new terminal after installing so the PATH
change takes effect, then run `omp` in a project directory. See the
[Oh My Pi documentation](https://omp.sh) for configuration and providers.
