# Apache Arrow Flight SQL ODBC Driver Chocolatey Package

## Install

```powershell
choco install arrow-flight-sql-odbc
```

Chocolatey downloads the official 64-bit installer at install time and runs it silently. The package itself carries no binaries.

Install a specific version:

```powershell
choco install arrow-flight-sql-odbc --version=<version>
```

## What is Apache Arrow Flight SQL ODBC Driver?

Apache Arrow is the universal columnar format and multi-language toolbox for fast data interchange and in-memory analytics.

## Upgrade

```powershell
choco upgrade arrow-flight-sql-odbc
```

## Uninstall

```powershell
choco uninstall arrow-flight-sql-odbc
```
