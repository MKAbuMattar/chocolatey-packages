# omniget Chocolatey Package

## What is omniget?

A free, open source desktop downloader for Windows, macOS and Linux. Paste a link from
YouTube, Instagram, TikTok, X, Reddit, Twitch or one of the sites yt-dlp supports and the
file lands in your folder: video, audio, image galleries, torrents and direct files, in
one queue with resume and retry. It installs and updates yt-dlp and FFmpeg by itself.

It also has an MCP server, so coding agents such as Claude Code can queue and track
downloads, and it can run AI coding agents in a desktop window.

Upstream also publishes a separate command line build, `omniget-cli`. This package
installs the desktop application.
