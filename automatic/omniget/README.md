# omniget Chocolatey Package

## What is omniget?

A desktop downloader for course platforms, video, music and books, covering more than
1,800 sites. It is free and open source, and it runs as a window rather than a command
line, so there is nothing to type to fetch something.

Upstream also publishes a separate command line build, `omniget-cli`. This package
installs the desktop application.
