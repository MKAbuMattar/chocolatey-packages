# AnythingLLM Desktop Chocolatey Package

## Install

```powershell
choco install anythingllm
```

Chocolatey downloads the official installer from the [Mintplex-Labs/anything-llm](https://github.com/Mintplex-Labs/anything-llm/releases) releases and runs it silently.

## What is AnythingLLM Desktop?

Stop renting your intelligence. Own it with AnythingLLM. Everything you need for a powerful local-first agent experience.

Upstream describes it with these topics: agent-computer, agent-harness, agent-orchestration, agentic-ai, ai-agents, computer-use, hermes-agent, llm.

## Upgrade

```powershell
choco upgrade anythingllm
```

## Uninstall

```powershell
choco uninstall anythingllm
```
