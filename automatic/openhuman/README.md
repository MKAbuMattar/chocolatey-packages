# OpenHuman Chocolatey Package

## Install

```powershell
choco install openhuman
```

Chocolatey downloads the official 64-bit installer at install time and runs it silently. The package itself carries no binaries.

Install a specific version:

```powershell
choco install openhuman --version=<version>
```

## What is OpenHuman?

OpenHuman is an open source agent harness with local-first memory, agent orchestration, and workflows.

## Upgrade

```powershell
choco upgrade openhuman
```

## Uninstall

```powershell
choco uninstall openhuman
```
