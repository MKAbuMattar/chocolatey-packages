# OpenFoot Manager Chocolatey Package

## Install

```powershell
choco install openfootmanager
```

Chocolatey downloads the official 64-bit installer at install time and runs it silently. The package itself carries no binaries.

Install a specific version:

```powershell
choco install openfootmanager --version=<version>
```

## What is OpenFoot Manager?

An open source soccer/football manager game

## Upgrade

```powershell
choco upgrade openfootmanager
```

## Uninstall

```powershell
choco uninstall openfootmanager
```
