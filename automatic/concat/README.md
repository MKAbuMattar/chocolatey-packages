# Concat Chocolatey Package

## Install

```powershell
choco install concat
```

Chocolatey downloads the official Windows build from the [jub0t/Concat](https://github.com/jub0t/Concat/releases) releases and puts it on your PATH.

## What is Concat?

Free & Open-Source CapCut replacement.

Upstream describes it with these topics: audio-processor, auto-caption, automation, capcut, capcut-alternative, content-creation, cross-platform, desktop-app.

## Upgrade

```powershell
choco upgrade concat
```

## Uninstall

```powershell
choco uninstall concat
```
