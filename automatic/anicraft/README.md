# AniCraft Chocolatey Package

## What is AniCraft?

AniCraft is an open-source 2D vector animation app written in Rust. You draw on a stage,
lay out layers on a timeline, and animate them with keyframes and classic tweens with
editable easing curves. It runs natively.

## Usage

The package installs the AniCraft desktop app. Start it from the Start Menu. See
[AniCraft on getartcraft.com](https://getartcraft.com/apps/anicraft) for more.

It also puts `anicraft-cli` on the PATH: `anicraft-cli mcp` runs
AniCraft's MCP server, so AI agents can drive the app.
