# DeepChat Chocolatey Package

## Install

```powershell
choco install deepchat
```

Chocolatey downloads the official 64-bit installer at install time and runs it silently. The package itself carries no binaries.

Install a specific version:

```powershell
choco install deepchat --version=<version>
```

## What is DeepChat?

DeepChat - A smart assistant that connects powerful AI to your personal world.

## Upgrade

```powershell
choco upgrade deepchat
```

## Uninstall

```powershell
choco uninstall deepchat
```
