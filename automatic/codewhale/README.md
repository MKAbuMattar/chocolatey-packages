# Codewhale Chocolatey Package

## What is Codewhale?

Codewhale is an open-source coding agent for the terminal, built in Rust. It reads and
edits code, runs commands and works through multi-step tasks in your project.

## Usage

The package installs the `codewhale` command, and its short form `codew`. Open a new
terminal after installing so the PATH change takes effect, then run `codewhale` in a
project directory.
