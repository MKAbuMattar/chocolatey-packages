# Open PDF Studio Chocolatey Package

## Install

```powershell
choco install open-pdf-studio
```

Chocolatey downloads the official installer from the [OpenAEC-Foundation/open-pdf-studio](https://github.com/OpenAEC-Foundation/open-pdf-studio/releases) releases and runs it silently.

## What is Open PDF Studio?

Open PDF Studio.

## Upgrade

```powershell
choco upgrade open-pdf-studio
```

## Uninstall

```powershell
choco uninstall open-pdf-studio
```
