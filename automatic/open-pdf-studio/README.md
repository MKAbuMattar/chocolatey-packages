# Open PDF Studio Chocolatey Package

## Install

```powershell
choco install open-pdf-studio
```

Chocolatey downloads the official 64-bit installer at install time and runs it silently. The package itself carries no binaries.

Install a specific version:

```powershell
choco install open-pdf-studio --version=<version>
```

## What is Open PDF Studio?

Open PDF Studio.

## Upgrade

```powershell
choco upgrade open-pdf-studio
```

## Uninstall

```powershell
choco uninstall open-pdf-studio
```
