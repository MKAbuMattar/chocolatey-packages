# Squad Chocolatey Package

## Install

```powershell
choco install squad
```

Chocolatey downloads the official Windows build from the [mco-org/squad](https://github.com/mco-org/squad/releases) releases and puts it on your PATH.

## What is Squad?

Multi-AI agent terminal collaboration tool.

## Upgrade

```powershell
choco upgrade squad
```

## Uninstall

```powershell
choco uninstall squad
```
