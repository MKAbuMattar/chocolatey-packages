# YTSage Chocolatey Package

## Install

```powershell
choco install ytsage
```

Chocolatey downloads the official installer from the [oop7/YTSage](https://github.com/oop7/YTSage/releases) releases and runs it silently.

## What is YTSage?

Modern YouTube downloader with a clean PySide6 interface. Download videos in any quality, extract audio, fetch subtitles, sponsorBlock, and view video metadata. Built with yt-dlp for reliable performance.

Upstream describes it with these topics: pyside6, python, youtube-dl, youtube-downloader, yt-dlp, yt-dlp-gui.

## Upgrade

```powershell
choco upgrade ytsage
```

## Uninstall

```powershell
choco uninstall ytsage
```
