# YTSage Chocolatey Package

## Install

```powershell
choco install ytsage
```

Chocolatey downloads the official 64-bit installer at install time and runs it silently. The package itself carries no binaries.

Install a specific version:

```powershell
choco install ytsage --version=<version>
```

## What is YTSage?

Modern YouTube downloader with a clean PySide6 interface. Download videos in any quality, extract audio, fetch subtitles, sponsorBlock, and view video metadata. Built with yt-dlp for reliable performance.

## Upgrade

```powershell
choco upgrade ytsage
```

## Uninstall

```powershell
choco uninstall ytsage
```
