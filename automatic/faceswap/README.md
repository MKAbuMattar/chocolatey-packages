# Faceswap Chocolatey Package

## Install

```powershell
choco install faceswap
```

Chocolatey downloads the official 64-bit installer at install time and runs it silently. The package itself carries no binaries.

Install a specific version:

```powershell
choco install faceswap --version=<version>
```

## What is Faceswap?

Deepfakes Software For All.

## Upgrade

```powershell
choco upgrade faceswap
```

## Uninstall

```powershell
choco uninstall faceswap
```
