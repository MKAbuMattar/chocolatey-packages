# Kortix Chocolatey Package

## Install

```powershell
choco install kortix
```

Chocolatey downloads the official installer from the [kortix-ai/suna](https://github.com/kortix-ai/suna/releases) releases and runs it silently.

## What is Kortix?

The Company AI Command Center.

Upstream describes it with these topics: ai, ai-agents, llm.

## Upgrade

```powershell
choco upgrade kortix
```

## Uninstall

```powershell
choco uninstall kortix
```
