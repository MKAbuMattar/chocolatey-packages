# Kortix Chocolatey Package

## Install

```powershell
choco install kortix
```

Chocolatey downloads the official 64-bit installer at install time and runs it silently. The package itself carries no binaries.

Install a specific version:

```powershell
choco install kortix --version=0.11.0
```

## What is Kortix?

The Company AI Command Center.

## Upgrade

```powershell
choco upgrade kortix
```

## Uninstall

```powershell
choco uninstall kortix
```
