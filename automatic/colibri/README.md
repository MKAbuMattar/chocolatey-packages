# Colibri Chocolatey Package

## Install

```powershell
choco install colibri
```

Chocolatey downloads the official 64-bit archive at install time, unpacks it into the package tools directory and shims the executables it contains. The package itself carries no binaries.

Install a specific version:

```powershell
choco install colibri --version=1.3.0
```

## What is Colibri?

Run frontier MoE models on hardware you already own , pure C, zero deps, experts streamed from disk. Tiny engine, immense model.

## Upgrade

```powershell
choco upgrade colibri
```

## Uninstall

```powershell
choco uninstall colibri
```
