# Colibri Chocolatey Package

## Install

```powershell
choco install colibri
```

Chocolatey downloads the official Windows build from the [JustVugg/colibri](https://github.com/JustVugg/colibri/releases) releases and puts it on your PATH.

## What is Colibri?

Run frontier MoE models on hardware you already own , pure C, zero deps, experts streamed from disk. Tiny engine, immense model.

## Upgrade

```powershell
choco upgrade colibri
```

## Uninstall

```powershell
choco uninstall colibri
```
