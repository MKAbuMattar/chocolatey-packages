# Dr.Claw Chocolatey Package

## Install

```powershell
choco install dr-claw
```

Chocolatey downloads the official 64-bit installer at install time and runs it silently. The package itself carries no binaries.

Install a specific version:

```powershell
choco install dr-claw --version=<version>
```

## What is Dr.Claw?

Dr.Claw, from OpenLAIR, is an open source AI science lab: a desktop application of AI researcher agents that plan experiments, run code and write up results.

## Upgrade

```powershell
choco upgrade dr-claw
```

## Uninstall

```powershell
choco uninstall dr-claw
```
