# Traccar Chocolatey Package

## Install

```powershell
choco install traccar
```

Chocolatey downloads the official installer from the [traccar/traccar](https://github.com/traccar/traccar/releases) releases and runs it silently.
The archive holds Traccar's own NSIS setup, which Chocolatey extracts and then runs silently.

## What is Traccar?

Open source GPS tracking platform - self-hosted or managed, 200+ device protocols.

Upstream describes it with these topics: docker, fleet-management, gps, gps-tracking, hacktoberfest, iot, java, open-source.

## Upgrade

```powershell
choco upgrade traccar
```

## Uninstall

```powershell
choco uninstall traccar
```
