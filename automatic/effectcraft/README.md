# EffectCraft Chocolatey Package

## What is EffectCraft?

EffectCraft is an open-source motion graphics and visual effects compositor written
in Rust: compositions, layers, keyframes, over 300 effects, expressions, 3D cameras
and lights, and a render queue. It follows the Adobe After Effects workflow as a
clean-room reimplementation.

## Usage

The package installs the EffectCraft desktop app. Start it from the Start Menu. See
[EffectCraft on getartcraft.com](https://getartcraft.com/apps/effectcraft) for more.
