# Task Manager TMOG Chocolatey Package

## What is Task Manager TMOG?

Task Manager TMOG is a task manager and system monitor from Dave Plummer, the original
author of Windows Task Manager. It shows system metrics, processes and performance
history in a native app, and adds a system-load screensaver and swappable skins.

The free edition is closed source and free to use under the license shipped with the
app. TMOG PRO is a paid upgrade with more features; see
[TMOG PRO](https://tmog.org/rtm/pro-info.html).

## Usage

The package installs Task Manager TMOG for all users. Start it from the Start Menu.
