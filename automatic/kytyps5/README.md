# KytyPS5 Chocolatey Package

## What is KytyPS5?

KytyPS5 is a free and open-source PlayStation 5 emulator written in C++, based on a
heavily modified version of [Kyty](https://github.com/InoriRus/Kyty). It is in active
development, and behaviour can change significantly between builds.

KytyPS5 is not affiliated with Sony Interactive Entertainment or PlayStation. It does not
distribute games or copyrighted system software; use only game files you have obtained
legally.

## Usage

The package installs the `kytyps5` command and a Start Menu shortcut, both of which open
the KytyPS5 launcher. See the [project README](https://github.com/KytyPS5/KytyPS5#readme)
for system requirements and current game compatibility.
