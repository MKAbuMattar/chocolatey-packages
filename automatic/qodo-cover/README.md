# Qodo Cover Chocolatey Package

## Install

```powershell
choco install qodo-cover
```

Chocolatey downloads the official 64-bit build at install time and puts it on your PATH. The package itself carries no binaries.

Install a specific version:

```powershell
choco install qodo-cover --version=0.3.10
```

## What is Qodo Cover?

Qodo-Cover: An AI-Powered Tool for Automated Test Generation and Code Coverage Enhancement!.

## Usage

The package installs the `cover-agent` command. Open a new terminal after installing so the PATH change takes effect, then see the [Qodo Cover documentation](https://qodo.ai/) for the available options.

## Upgrade

```powershell
choco upgrade qodo-cover
```

## Uninstall

```powershell
choco uninstall qodo-cover
```
