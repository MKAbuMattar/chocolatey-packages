# Qodo Cover Chocolatey Package

## Install

```powershell
choco install qodo-cover
```

Chocolatey downloads the official Windows build from the [qodo-ai/qodo-cover](https://github.com/qodo-ai/qodo-cover/releases) releases and puts it on your PATH.

## What is Qodo Cover?

Qodo-Cover: An AI-Powered Tool for Automated Test Generation and Code Coverage Enhancement!.

Upstream describes it with these topics: agents, ai, test-automation, testing.

## Upgrade

```powershell
choco upgrade qodo-cover
```

## Uninstall

```powershell
choco uninstall qodo-cover
```
