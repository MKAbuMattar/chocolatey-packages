# Flux Operator Chocolatey Package

## Install

```powershell
choco install flux-operator
```

Chocolatey downloads the official Windows build from the [controlplaneio-fluxcd/flux-operator](https://github.com/controlplaneio-fluxcd/flux-operator/releases) releases and puts it on your PATH.
This installs the Flux Operator command line tool. The operator itself runs in Kubernetes.

## What is Flux Operator?

GitOps on Autopilot Mode.

Upstream describes it with these topics: continuous-delivery, flux-ui, fluxcd, gitops, mcp-server.

## Upgrade

```powershell
choco upgrade flux-operator
```

## Uninstall

```powershell
choco uninstall flux-operator
```
