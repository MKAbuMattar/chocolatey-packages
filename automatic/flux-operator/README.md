# Flux Operator Chocolatey Package

## Install

```powershell
choco install flux-operator
```

Chocolatey downloads the official 64-bit archive at install time, unpacks it into the package tools directory and shims the executables it contains. The package itself carries no binaries.

Install a specific version:

```powershell
choco install flux-operator --version=0.58.0
```

## What is Flux Operator?

GitOps on Autopilot Mode.

## Upgrade

```powershell
choco upgrade flux-operator
```

## Uninstall

```powershell
choco uninstall flux-operator
```
