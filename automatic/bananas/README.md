# Bananas Chocolatey Package

## Install

```powershell
choco install bananas
```

Chocolatey downloads the official installer from the [mistweaverco/bananas](https://github.com/mistweaverco/bananas/releases) releases and runs it silently.

## What is Bananas?

Bananas, Cross-Platform screen sharing made simple.

Upstream describes it with these topics: cross-platform, multi-cursor, p2p, pair-programming, pairing, peer-to-peer, screensharing.

## Upgrade

```powershell
choco upgrade bananas
```

## Uninstall

```powershell
choco uninstall bananas
```
