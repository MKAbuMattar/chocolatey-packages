# mesheryctl Chocolatey Package

## Install

```powershell
choco install mesheryctl
```

Chocolatey downloads the official Windows build from the [meshery/meshery](https://github.com/meshery/meshery/releases) releases and puts it on your PATH.

## What is mesheryctl?

Meshery, the cloud native manager.

Upstream describes it with these topics: cloud-native, cncf, control-plane, docker, gitops, golang, gsoc, hacktoberfest.

## Upgrade

```powershell
choco upgrade mesheryctl
```

## Uninstall

```powershell
choco uninstall mesheryctl
```
