# mesheryctl Chocolatey Package

## Install

```powershell
choco install mesheryctl
```

Chocolatey downloads the official 64-bit archive at install time, unpacks it into the package tools directory and shims the executables it contains. The package itself carries no binaries.

Install a specific version:

```powershell
choco install mesheryctl --version=1.0.63
```

## What is mesheryctl?

Meshery, the cloud native manager.

## Upgrade

```powershell
choco upgrade mesheryctl
```

## Uninstall

```powershell
choco uninstall mesheryctl
```
