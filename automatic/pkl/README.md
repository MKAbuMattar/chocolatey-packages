# Pkl Chocolatey Package

## Install

```powershell
choco install pkl
```

Chocolatey downloads the official 64-bit build at install time and puts it on your PATH. The package itself carries no binaries.

Install a specific version:

```powershell
choco install pkl --version=<version>
```

## What is Pkl?

A configuration as code language with rich validation and tooling.

## Usage

The package installs the `pkl` command. Open a new terminal after installing so the PATH change takes effect, then see the [Pkl documentation](https://pkl-lang.org) for the available options.

## Upgrade

```powershell
choco upgrade pkl
```

## Uninstall

```powershell
choco uninstall pkl
```
