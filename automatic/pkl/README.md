# Pkl Chocolatey Package

## Install

```powershell
choco install pkl
```

Chocolatey downloads the official Windows build from the [apple/pkl](https://github.com/apple/pkl/releases) releases and puts it on your PATH.

## What is Pkl?

A configuration as code language with rich validation and tooling.

Upstream describes it with these topics: config, configuration, data, functional, java, json, kotlin, language.

## Upgrade

```powershell
choco upgrade pkl
```

## Uninstall

```powershell
choco uninstall pkl
```
