# SoundCraft Chocolatey Package

## What is SoundCraft?

SoundCraft is an open-source digital audio workstation written in Rust. It follows
the Avid Pro Tools workflow as a clean-room reimplementation: multitrack editing,
a mixer with plugins, sends and automation, MIDI, recording and bouncing. It runs
natively.

## Usage

The package installs the SoundCraft desktop app. Start it from the Start Menu. See the
[project README](https://github.com/storytold/soundcraft#readme) for more.
