# Herdr Chocolatey Package

## What is Herdr?

Herdr is a desktop app for terminals and coding agents. You keep work in spaces, see
which agents need you, and leave terminals running when you close the window.

This is the desktop app. The `herdr` package is the separate herdr command-line
runtime.

## Usage

The package installs Herdr with a Start Menu shortcut and the `herdr-app` command.
Herdr runs on herdr-core, which it offers to install the first time it opens.
