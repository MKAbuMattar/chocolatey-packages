# OpenIDEA Chocolatey Package

## What is OpenIDEA?

OpenIDEA is the IDE you know, rebuilt in Rust. It brings the IntelliJ IDEA way of
working, its keymap, its tool windows and its search-everywhere habits, to a fast native
app. It ships an editor, code insight, a debugger, Git, a terminal, and database and HTTP
clients for 60+ languages.

## Usage

The package installs the OpenIDEA desktop app. Start it from the Start Menu and open a
project. See [github.com/l0ng-ai/openidea](https://github.com/l0ng-ai/openidea) for more.
