# Flet Chocolatey Package

## Install

```powershell
choco install flet
```

Chocolatey downloads the official 64-bit archive at install time, unpacks it into the package tools directory and shims the executables it contains. The package itself carries no binaries.

Install a specific version:

```powershell
choco install flet --version=<version>
```

## What is Flet?

Build realtime web, mobile and desktop apps in Python only. No frontend experience required.

## Upgrade

```powershell
choco upgrade flet
```

## Uninstall

```powershell
choco uninstall flet
```
