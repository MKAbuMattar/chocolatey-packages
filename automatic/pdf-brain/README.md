# pdf-brain Chocolatey Package

## Install

```powershell
choco install pdf-brain
```

Chocolatey downloads the official 64-bit build at install time and puts it on your PATH. The package itself carries no binaries.

Install a specific version:

```powershell
choco install pdf-brain --version=<version>
```

## What is pdf-brain?

Local PDF knowledge base with vector search using libsql w/vectors

## Usage

The package installs the `pdf-brain` command. Open a new terminal after installing so the PATH change takes effect, then see the [pdf-brain documentation](https://github.com/joelhooks/pdf-brain) for the available options.

## Upgrade

```powershell
choco upgrade pdf-brain
```

## Uninstall

```powershell
choco uninstall pdf-brain
```
