# CADCraft Chocolatey Package

## What is CADCraft?

CADCraft is an open-source computer-aided design and drafting app written in Rust.
It follows the Autodesk AutoCAD workflow as a clean-room reimplementation: the
command line, object snaps, layers, dimensions, hatches, blocks and DXF drawings.
It runs natively.

## Usage

The package installs the CADCraft desktop app. Start it from the Start Menu. See the
[project README](https://github.com/storytold/cadcraft#readme) for more.
