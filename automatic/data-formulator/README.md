# Data Formulator Chocolatey Package

## Install

```powershell
choco install data-formulator
```

Chocolatey downloads the official Windows build from the [microsoft/data-formulator](https://github.com/microsoft/data-formulator/releases) releases and puts it on your PATH.
Upstream tags betas as 0.8b1, published here as the pre-release 0.8-b1.

## What is Data Formulator?

Data Formulator is an interactive AI-powered data analysis system makes it easy to connect, explore and visualize data.

## Upgrade

```powershell
choco upgrade data-formulator
```

## Uninstall

```powershell
choco uninstall data-formulator
```
