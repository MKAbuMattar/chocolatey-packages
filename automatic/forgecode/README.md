# Forge Code Chocolatey Package

## What is Forge Code?

Forge Code is an AI pair programmer for the terminal. It works with Claude, GPT, Grok,
DeepSeek, Gemini and more than 300 other models.

## Usage

The package installs the `forge` command. Open a new terminal after installing so the
PATH change takes effect, then run `forge` in a project directory. The package id is
`forgecode` because `forge` is taken by another package.
