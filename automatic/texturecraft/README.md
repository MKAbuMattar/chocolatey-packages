# TextureCraft Chocolatey Package

## What is TextureCraft?

TextureCraft is an open-source 3D texture painting app written in Rust. You paint PBR
materials onto models in layers with masks, bake mesh maps, drive smart materials from
them, and export textures for any engine. It runs natively.

## Usage

The package installs the TextureCraft desktop app. Start it from the Start Menu. See
[TextureCraft on getartcraft.com](https://getartcraft.com/apps/texturecraft) for more.
