# Numbat Chocolatey Package

## Install

```powershell
choco install numbat-agent
```

Chocolatey downloads the official 64-bit archive at install time, unpacks it into the package tools directory and shims the executables it contains. The package itself carries no binaries.

Install a specific version:

```powershell
choco install numbat-agent --version=0.1.2
```

## What is Numbat?

Visibility into AI agent activity on endpoints, with on-device detection, optional pre-action blocking, and forensic reconstruction.

## Upgrade

```powershell
choco upgrade numbat-agent
```

## Uninstall

```powershell
choco uninstall numbat-agent
```
