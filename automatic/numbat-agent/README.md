# Numbat Chocolatey Package

## Install

```powershell
choco install numbat-agent
```

Chocolatey downloads the official Windows build from the [perplexityai/numbat](https://github.com/perplexityai/numbat/releases) releases and puts it on your PATH.
The package id is `numbat-agent` rather than `numbat`, to leave that name to the unit calculator of the same name. The command it installs is still `numbat`.

## What is Numbat?

Visibility into AI agent activity on endpoints, with on-device detection, optional pre-action blocking, and forensic reconstruction.

Upstream describes it with these topics: agent-security, ai-agent-security, ai-agents.

## Upgrade

```powershell
choco upgrade numbat-agent
```

## Uninstall

```powershell
choco uninstall numbat-agent
```
