# Manta Chocolatey Package

## Install

```powershell
choco install manta
```

Chocolatey downloads the official 64-bit installer at install time and runs it silently. The package itself carries no binaries.

Install a specific version:

```powershell
choco install manta --version=<version>
```

## What is Manta?

Flexible invoicing desktop app with beautiful & customizable templates.

## Upgrade

```powershell
choco upgrade manta
```

## Uninstall

```powershell
choco uninstall manta
```
