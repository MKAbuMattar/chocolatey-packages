# Ever Gauzy Agent Chocolatey Package

## Install

```powershell
choco install ever-gauzy
```

Chocolatey downloads the official installer from the [ever-co/ever-gauzy](https://github.com/ever-co/ever-gauzy/releases) releases and runs it silently.

## What is Ever Gauzy Agent?

Ever® Gauzy™ - Open Business Management Platform (ERP/CRM/HRM/ATS/PM) - https://gauzy.co.

Upstream describes it with these topics: accounting, billing, bookkeeping, crm, crm-platform, erp, expenses, hr.

## Upgrade

```powershell
choco upgrade ever-gauzy
```

## Uninstall

```powershell
choco uninstall ever-gauzy
```
