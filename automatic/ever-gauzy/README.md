# Ever Gauzy Agent Chocolatey Package

## Install

```powershell
choco install ever-gauzy
```

Chocolatey downloads the official 64-bit installer at install time and runs it silently. The package itself carries no binaries.

Install a specific version:

```powershell
choco install ever-gauzy --version=111.0.11
```

## What is Ever Gauzy Agent?

Ever® Gauzy™ - Open Business Management Platform (ERP/CRM/HRM/ATS/PM) - https://gauzy.co.

## Upgrade

```powershell
choco upgrade ever-gauzy
```

## Uninstall

```powershell
choco uninstall ever-gauzy
```
