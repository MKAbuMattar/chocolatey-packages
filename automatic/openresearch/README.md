# OpenResearch Chocolatey Package

## Install

```powershell
choco install openresearch
```

Chocolatey downloads the official 64-bit build at install time and puts it on your PATH. The package itself carries no binaries.

Install a specific version:

```powershell
choco install openresearch --version=<version>
```

## What is OpenResearch?

OpenResearch, from alphaXiv, turns coding agents into research agents: it reads papers, runs arXiv searches and folds findings into your work from the terminal.

## Usage

The package installs the `orx` command. Open a new terminal after installing so the PATH change takes effect.

## Upgrade

```powershell
choco upgrade openresearch
```

## Uninstall

```powershell
choco uninstall openresearch
```
