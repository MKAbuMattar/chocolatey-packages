# Debug Skill Chocolatey Package

## Install

```powershell
choco install debug-skill
```

Chocolatey downloads the official Windows build from the [AlmogBaku/debug-skill](https://github.com/AlmogBaku/debug-skill/releases) releases and puts it on your PATH.
Installs the `dap` binary that the project ships.

## What is Debug Skill?

Debug Skill.

## Upgrade

```powershell
choco upgrade debug-skill
```

## Uninstall

```powershell
choco uninstall debug-skill
```
