# LeanCTX Chocolatey Package

## Install

```powershell
choco install lean-ctx
```

Chocolatey downloads the official 64-bit build at install time and puts it on your PATH. The package itself carries no binaries.

Install a specific version:

```powershell
choco install lean-ctx --version=<version>
```

## What is LeanCTX?

LeanCTX is context intelligence for AI systems: it compresses and curates what an AI coding agent sees, so large repositories fit the context window without losing what matters.

## Usage

The package installs the `lean-ctx` command. Open a new terminal after installing so the PATH change takes effect.

## Upgrade

```powershell
choco upgrade lean-ctx
```

## Uninstall

```powershell
choco uninstall lean-ctx
```
