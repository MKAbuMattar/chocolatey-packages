# IWE Chocolatey Package

## Install

```powershell
choco install iwe
```

Chocolatey downloads the official 64-bit archive at install time, unpacks it into the package tools directory and shims the executables it contains. The package itself carries no binaries.

Install a specific version:

```powershell
choco install iwe --version=<version>
```

## What is IWE?

Markdown knowledge graph — LSP for your editor, CLI + MCP memory for your AI agents

## Upgrade

```powershell
choco upgrade iwe
```

## Uninstall

```powershell
choco uninstall iwe
```
