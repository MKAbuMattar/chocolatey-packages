# NeoHtop Chocolatey Package

## Install

```powershell
choco install neohtop
```

Chocolatey downloads the official Windows build from the [Abdenasser/neohtop](https://github.com/Abdenasser/neohtop/releases) releases and puts it on your PATH.

## What is NeoHtop?

Blazing-fast system monitoring for your desktop (built with Rust, Tauri & Svelte).

Upstream describes it with these topics: activity, btop, cross-platform, htop, monitoring, rust, svelte, system.

## Upgrade

```powershell
choco upgrade neohtop
```

## Uninstall

```powershell
choco uninstall neohtop
```
