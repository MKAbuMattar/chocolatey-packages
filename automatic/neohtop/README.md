# NeoHtop Chocolatey Package

## What is NeoHtop?

Blazing-fast system monitoring for your desktop (built with Rust, Tauri & Svelte).

## Usage

The package installs the `NeoHtop` command. Open a new terminal after installing so the PATH change takes effect, then see the [NeoHtop documentation](https://abdenasser.github.io/neohtop/) for the available options.
