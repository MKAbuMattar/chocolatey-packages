# NeoHtop Chocolatey Package

## Install

```powershell
choco install neohtop
```

Chocolatey downloads the official 64-bit build at install time and puts it on your PATH. The package itself carries no binaries.

Install a specific version:

```powershell
choco install neohtop --version=1.2.0
```

## What is NeoHtop?

Blazing-fast system monitoring for your desktop (built with Rust, Tauri & Svelte).

## Usage

The package installs the `NeoHtop` command. Open a new terminal after installing so the PATH change takes effect, then see the [NeoHtop documentation](https://abdenasser.github.io/neohtop/) for the available options.

## Upgrade

```powershell
choco upgrade neohtop
```

## Uninstall

```powershell
choco uninstall neohtop
```
