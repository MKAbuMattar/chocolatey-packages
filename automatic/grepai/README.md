# grepai Chocolatey Package

## Install

```powershell
choco install grepai
```

Chocolatey downloads the official Windows build from the [yoanbernabeu/grepai](https://github.com/yoanbernabeu/grepai/releases) releases and puts it on your PATH.

## What is grepai?

Semantic Search & Call Graphs for AI Agents (100% Local).

Upstream describes it with these topics: ai, claude-code, cli, code-search, cursor, developer-tools, embeddings, golang.

## Upgrade

```powershell
choco upgrade grepai
```

## Uninstall

```powershell
choco uninstall grepai
```
