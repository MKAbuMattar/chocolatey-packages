# grepai Chocolatey Package

## Install

```powershell
choco install grepai
```

Chocolatey downloads the official 64-bit archive at install time, unpacks it into the package tools directory and shims the executables it contains. The package itself carries no binaries.

Install a specific version:

```powershell
choco install grepai --version=0.35.0
```

## What is grepai?

Semantic Search & Call Graphs for AI Agents (100% Local).

## Upgrade

```powershell
choco upgrade grepai
```

## Uninstall

```powershell
choco uninstall grepai
```
