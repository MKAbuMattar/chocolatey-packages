# winapp CLI Chocolatey Package

## Install

```powershell
choco install winapp
```

Chocolatey downloads the official Windows build from the [microsoft/winappCli](https://github.com/microsoft/winappCli/releases) releases and puts it on your PATH.

## What is winapp CLI?

winapp, the Windows App Development CLI, is a single command-line interface for managing Windows SDKs, packaging, generating app identity, manifests, certificates, and using build tools with any app framework.

Upstream describes it with these topics: cli, electron, identity, msix, winappsdk, windev, windows, windows-development.

## Upgrade

```powershell
choco upgrade winapp
```

## Uninstall

```powershell
choco uninstall winapp
```
