# txm Chocolatey Package

## Install

```powershell
choco install txm
```

Chocolatey downloads the official Windows build from the [thatmagicalcat/txm](https://github.com/thatmagicalcat/txm/releases) releases and puts it on your PATH.

## What is txm?

Terminal Math rendering engine.

## Upgrade

```powershell
choco upgrade txm
```

## Uninstall

```powershell
choco uninstall txm
```
