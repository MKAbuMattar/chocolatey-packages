# Pyrefly Chocolatey Package

## What is Pyrefly?

Pyrefly is a fast type checker and language server for Python, written in Rust. It
checks large codebases in seconds, infers types for unannotated code, and powers IDE
features such as go-to-definition, hover and completions.

## Usage

The package puts `pyrefly` on the PATH. Run `pyrefly init` in a project to create its
config, then `pyrefly check` to type check it. See [pyrefly.org](https://pyrefly.org/)
for more.
