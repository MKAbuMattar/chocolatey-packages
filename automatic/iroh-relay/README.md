# iroh relay Chocolatey Package

## Install

```powershell
choco install iroh-relay
```

Chocolatey downloads the official 64-bit archive at install time, unpacks it into the package tools directory and shims the executables it contains. The package itself carries no binaries.

Install a specific version:

```powershell
choco install iroh-relay --version=1.0.3
```

## What is iroh relay?

IP addresses break, dial keys instead. A library that adds QUIC + NAT Traversal to your apps.

## Upgrade

```powershell
choco upgrade iroh-relay
```

## Uninstall

```powershell
choco uninstall iroh-relay
```
