# iroh relay Chocolatey Package

## Install

```powershell
choco install iroh-relay
```

Chocolatey downloads the official Windows build from the [n0-computer/iroh](https://github.com/n0-computer/iroh/releases) releases and puts it on your PATH.
iroh is a library. This package installs the relay server it ships, not iroh itself.

## What is iroh relay?

IP addresses break, dial keys instead. A library that adds QUIC + NAT Traversal to your apps.

Upstream describes it with these topics: does-anyone-read-these, holepunching, memes, multipath, p2p, quic, realtime, rust.

## Upgrade

```powershell
choco upgrade iroh-relay
```

## Uninstall

```powershell
choco uninstall iroh-relay
```
