# Xiaomi MiMo AI Chocolatey Package

## What is Xiaomi MiMo AI?

Xiaomi MiMo AI is the desktop client of Xiaomi MiMo. One conversation can handle office
work, design, coding and multimodal creation, and several conversations can split a
task and work on it in parallel. It uses [MiMo Code](https://github.com/XiaomiMiMo/MiMo-Code)
as its core engine.

The desktop app is in beta. The international version needs an invitation to use,
which you can apply for at <https://mimo-ai.xiaomimimo.com/desktop/invite/>.

## Usage

The package installs the Xiaomi MiMo AI desktop app. Start it from the Start Menu and
sign in.
