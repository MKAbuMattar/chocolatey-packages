# OctoBot Chocolatey Package

## What is OctoBot?

Free open source crypto trading bot to automate AI, Grid, DCA and TradingView strategies on Binance, Hyperliquid and 15+ exchanges, with a simple interface.

## Usage

The package installs the `OctoBot` command. Open a new terminal after installing so the PATH change takes effect, then see the [OctoBot documentation](https://www.octobot.cloud) for the available options.
