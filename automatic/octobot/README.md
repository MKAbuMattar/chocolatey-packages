# OctoBot Chocolatey Package

## Install

```powershell
choco install octobot
```

Chocolatey downloads the official Windows build from the [Drakkar-Software/OctoBot](https://github.com/Drakkar-Software/OctoBot/releases) releases and puts it on your PATH.

## What is OctoBot?

Free open source crypto trading bot to automate AI, Grid, DCA and TradingView strategies on Binance, Hyperliquid and 15+ exchanges, with a simple interface.

Upstream describes it with these topics: ai-trading, backtest, binance-api, bitcoin, coinbase-bot, cryptocurrencies, free, hyperliquid-trading-bot.

## Upgrade

```powershell
choco upgrade octobot
```

## Uninstall

```powershell
choco uninstall octobot
```
