# SharpEmu Chocolatey Package

## What is SharpEmu?

SharpEmu is an experimental, open-source PlayStation 5 emulator written in C#. It runs
PS5 executables directly on the host x86-64 CPU and renders through Vulkan. It is in
early development, and game compatibility varies widely between titles and builds.

It is not affiliated with Sony Interactive Entertainment. It does not provide games or
system software; use only game files you have obtained legally.

## Usage

The package installs the `sharpemu` command and a Start Menu shortcut, both of which open
SharpEmu. See the [project README](https://github.com/sharpemu/sharpemu#readme) for requirements and
game compatibility.
