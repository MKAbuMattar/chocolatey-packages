# e2ecp Chocolatey Package

## Install

```powershell
choco install e2ecp
```

Chocolatey downloads the official Windows build from the [schollz/e2ecp](https://github.com/schollz/e2ecp/releases) releases and puts it on your PATH.

## What is e2ecp?

End-to-end encrypted copy file tool.

## Upgrade

```powershell
choco upgrade e2ecp
```

## Uninstall

```powershell
choco uninstall e2ecp
```
