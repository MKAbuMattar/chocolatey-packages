# e2ecp Chocolatey Package

## Install

```powershell
choco install e2ecp
```

Chocolatey downloads the official 64-bit archive at install time, unpacks it into the package tools directory and shims the executables it contains. The package itself carries no binaries.

Install a specific version:

```powershell
choco install e2ecp --version=<version>
```

## What is e2ecp?

End-to-end encrypted copy file tool.

## Upgrade

```powershell
choco upgrade e2ecp
```

## Uninstall

```powershell
choco uninstall e2ecp
```
