# pi Chocolatey Package

## Install

```powershell
choco install pi
```

Chocolatey downloads the official Windows build from the [earendil-works/pi](https://github.com/earendil-works/pi/releases) releases and puts it on your PATH.

## What is pi?

AI agent toolkit: unified LLM API, agent loop, TUI, coding agent CLI.

## Upgrade

```powershell
choco upgrade pi
```

## Uninstall

```powershell
choco uninstall pi
```
