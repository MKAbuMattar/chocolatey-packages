# File Browser Chocolatey Package

## Install

```powershell
choco install filebrowser
```

Chocolatey downloads the official Windows build from the [filebrowser/filebrowser](https://github.com/filebrowser/filebrowser/releases) releases and puts it on your PATH.

## What is File Browser?

Web File Browser.

Upstream describes it with these topics: file-browser, file-manager, file-sharing, go, material-design, self-hosted, vue.

## Upgrade

```powershell
choco upgrade filebrowser
```

## Uninstall

```powershell
choco uninstall filebrowser
```
