# File Browser Chocolatey Package

## Install

```powershell
choco install filebrowser
```

Chocolatey downloads the official 64-bit archive at install time, unpacks it into the package tools directory and shims the executables it contains. The package itself carries no binaries.

Install a specific version:

```powershell
choco install filebrowser --version=2.63.23
```

## What is File Browser?

Web File Browser.

## Upgrade

```powershell
choco upgrade filebrowser
```

## Uninstall

```powershell
choco uninstall filebrowser
```
