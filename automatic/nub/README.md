# nub Chocolatey Package

## Install

```powershell
choco install nub
```

Chocolatey downloads the official Windows build from the [nubjs/nub](https://github.com/nubjs/nub/releases) releases and puts it on your PATH.
The archive also bundles helper executables. Those are left out of your PATH so they cannot shadow tools you already have installed.

## What is nub?

The fast all-in-one Node.js toolkit.

Upstream describes it with these topics: javascript-runtime, node-version-manager, nodejs, package-manager, script-runner.

## Upgrade

```powershell
choco upgrade nub
```

## Uninstall

```powershell
choco uninstall nub
```
