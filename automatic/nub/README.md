# nub Chocolatey Package

## Install

```powershell
choco install nub
```

Chocolatey downloads the official 64-bit archive at install time, unpacks it into the package tools directory and shims the executables it contains. The package itself carries no binaries.

Install a specific version:

```powershell
choco install nub --version=<version>
```

## What is nub?

The fast all-in-one Node.js toolkit.

## Upgrade

```powershell
choco upgrade nub
```

## Uninstall

```powershell
choco uninstall nub
```
