# Openwork Chocolatey Package

## What is Openwork?

OpenWork is a free, open-source desktop app for sharing AI workflows, and an
open-source alternative to Claude Cowork and Codex.

It adds one MCP server to Codex, Claude Code, Cursor or another compatible agent, so
the same skills, MCP connections and connected services carry across your tools,
teammates and machines. The desktop app gives you a dedicated workspace, but it is
optional: OpenWork also works from the agent you already use.
