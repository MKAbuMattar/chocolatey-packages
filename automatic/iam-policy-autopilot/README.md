# IAM Policy Autopilot Chocolatey Package

## Install

```powershell
choco install iam-policy-autopilot
```

Chocolatey downloads the official 64-bit archive at install time, unpacks it into the package tools directory and shims the executables it contains. The package itself carries no binaries.

Install a specific version:

```powershell
choco install iam-policy-autopilot --version=<version>
```

## What is IAM Policy Autopilot?

IAM Policy Autopilot is an open source static code analysis tool that helps you quickly create baseline AWS IAM policies that you can refine as your application evolves. This tool is available as a command-line utility and MCP server for use within AI coding assistants for quickly building IAM policies.

## Upgrade

```powershell
choco upgrade iam-policy-autopilot
```

## Uninstall

```powershell
choco uninstall iam-policy-autopilot
```
