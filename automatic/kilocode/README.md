# Kilo Code Chocolatey Package

## Install

```powershell
choco install kilocode
```

Chocolatey downloads the official Windows build from the [Kilo-Org/kilocode](https://github.com/Kilo-Org/kilocode/releases) releases and puts the `kilo` command on your PATH.

This package installs the command line agent. Kilo Code also runs inside VS Code and JetBrains, and those are installed from the editor's own marketplace rather than from here, so they update with the editor.

## What is Kilo Code?

Kilo is the all-in-one agentic engineering platform. Build, ship, and iterate faster with the most popular open source coding agent.

Upstream describes it with these topics: ai, ai-age, ai-coding, ai-developer-tools, chatgpt, claude, cli, gemini.

## Upgrade

```powershell
choco upgrade kilocode
```

## Uninstall

```powershell
choco uninstall kilocode
```
