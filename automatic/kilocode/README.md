# Kilo Code Chocolatey Package

## Install

```powershell
choco install kilocode
```

Chocolatey downloads the official Windows build from the [Kilo-Org/kilocode](https://github.com/Kilo-Org/kilocode/releases) releases and puts it on your PATH.
Kilo Code is a VS Code fork, so this is a large unpack-and-run archive rather than an installer.

## What is Kilo Code?

Kilo is the all-in-one agentic engineering platform. Build, ship, and iterate faster with the most popular open source coding agent.

Upstream describes it with these topics: ai, ai-age, ai-coding, ai-developer-tools, chatgpt, claude, cli, gemini.

## Upgrade

```powershell
choco upgrade kilocode
```

## Uninstall

```powershell
choco uninstall kilocode
```
