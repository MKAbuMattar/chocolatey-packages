# LLRT Chocolatey Package

## Install

```powershell
choco install llrt
```

Chocolatey downloads the official 64-bit archive at install time, unpacks it into the package tools directory and shims the executables it contains. The package itself carries no binaries.

Install a specific version:

```powershell
choco install llrt --version=<version>
```

## What is LLRT?

LLRT (Low Latency Runtime) is an experimental, lightweight JavaScript runtime designed to address the growing demand for fast and efficient Serverless applications.

## Upgrade

```powershell
choco upgrade llrt
```

## Uninstall

```powershell
choco uninstall llrt
```
