# SolidCraft Chocolatey Package

## What is SolidCraft?

SolidCraft is an open-source parametric 3D CAD application written in Rust. You sketch,
constrain and build solids on a parametric feature timeline, and the model rebuilds when
you change a dimension. AI agents can model through its built-in MCP server.

## Usage

The package installs the SolidCraft desktop app. Start it from the Start Menu. See
[solidcraft.io](https://solidcraft.io) for more.
