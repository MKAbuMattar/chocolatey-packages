# p2p.kiwi Chocolatey Package

## Install

```powershell
choco install p2p-kiwi
```

Chocolatey downloads the official installer from the [dont-be-evil-company/p2p.kiwi](https://github.com/dont-be-evil-company/p2p.kiwi/releases) releases and runs it silently.
From the same team as Bananas, which this repository also packages.

## What is p2p.kiwi?

p2p.kiwi , Cross-Platform screen sharing made simple.

Upstream describes it with these topics: cross-platform, multi-cursor, p2p, pair-programming, pairing, peer-to-peer, screensharing.

## Upgrade

```powershell
choco upgrade p2p-kiwi
```

## Uninstall

```powershell
choco uninstall p2p-kiwi
```
