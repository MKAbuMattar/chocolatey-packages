# Onlook Chocolatey Package

## Install

```powershell
choco install onlook
```

Chocolatey downloads the official installer from the [onlook-dev/onlook](https://github.com/onlook-dev/onlook/releases) releases and runs it silently.

## What is Onlook?

The Cursor for Designers • An Open-Source AI-First Design tool • Visually build, style, and edit your React App with AI.

Upstream describes it with these topics: ai, cursor, cursor-ai, design, design-to-code, drizzle, editor, figma.

## Upgrade

```powershell
choco upgrade onlook
```

## Uninstall

```powershell
choco uninstall onlook
```
