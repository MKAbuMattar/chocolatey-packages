# Onlook Chocolatey Package

## Install

```powershell
choco install onlook
```

Chocolatey downloads the official 64-bit installer at install time and runs it silently. The package itself carries no binaries.

Install a specific version:

```powershell
choco install onlook --version=<version>
```

## What is Onlook?

The Cursor for Designers • An Open-Source AI-First Design tool • Visually build, style, and edit your React App with AI.

## Upgrade

```powershell
choco upgrade onlook
```

## Uninstall

```powershell
choco uninstall onlook
```
