# GitHub Copilot CLI Chocolatey Package

## Install

```powershell
choco install copilot-cli
```

Chocolatey downloads the official 64-bit installer at install time and runs it silently. The package itself carries no binaries.

Install a specific version:

```powershell
choco install copilot-cli --version=<version>
```

## What is GitHub Copilot CLI?

GitHub Copilot CLI brings the power of Copilot coding agent directly to your terminal.

## Upgrade

```powershell
choco upgrade copilot-cli
```

## Uninstall

```powershell
choco uninstall copilot-cli
```
