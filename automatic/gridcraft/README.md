# GridCraft Chocolatey Package

## What is GridCraft?

GridCraft is an open-source spreadsheet app written in Rust. It follows the
Microsoft Excel workflow as a clean-room reimplementation, with tables,
conditional formatting, sparklines and charts, and runs natively.

## Usage

The package installs the GridCraft desktop app. Start it from the Start Menu. See the
[project README](https://github.com/storytold/gridcraft#readme) for more.
