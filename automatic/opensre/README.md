# OpenSRE Chocolatey Package

## Install

```powershell
choco install opensre
```

Chocolatey downloads the official Windows build from the [Tracer-Cloud/opensre](https://github.com/Tracer-Cloud/opensre/releases) releases and puts it on your PATH.

## What is OpenSRE?

Build your own AI SRE agents. The open source toolkit for the AI era.

Upstream describes it with these topics: ai-sre, alerting, datadog, grafana, incident-management, observability, remediation, root-cause-analysis.

## Upgrade

```powershell
choco upgrade opensre
```

## Uninstall

```powershell
choco uninstall opensre
```
