# Terax Chocolatey Package

## Install

```powershell
choco install terax
```

Chocolatey downloads the official 64-bit installer at install time and runs it silently. The package itself carries no binaries.

Install a specific version:

```powershell
choco install terax --version=<version>
```

## What is Terax?

Lightweight (7MB) Terminal-first AI-native dev workspace.

## Upgrade

```powershell
choco upgrade terax
```

## Uninstall

```powershell
choco uninstall terax
```
