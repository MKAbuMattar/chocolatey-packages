# FieldCraft Chocolatey Package

## What is FieldCraft?

FieldCraft is an open-source engineering simulation (CAE) application written in Rust.
It takes a parametric [SolidCraft](https://solidcraft.io) part to a verified analysis:
tetrahedral and hexahedral meshing, its own nonlinear implicit, explicit and thermal
finite element solvers, lattice Boltzmann CFD, and decks for Abaqus, Nastran and
LS-DYNA. The desktop app, the command line and AI agents (over MCP) drive the same
commands.

It is early software: it works end to end, and its roadmap lists what is still missing.

## Usage

The package installs FieldCraft's portable build, with a Start Menu shortcut and the
`fieldcraft` and `fieldcraft-cli` commands. See the
[FieldCraft site](https://tangency-labs.github.io/fieldcraft/) for more.
