# HTTPie Desktop Chocolatey Package

## Install

```powershell
choco install httpie-desktop
```

Chocolatey downloads the official 64-bit installer at install time and runs it silently. The package itself carries no binaries.

Install a specific version:

```powershell
choco install httpie-desktop --version=<version>
```

## What is HTTPie Desktop?

HTTPie Desktop — cross-platform API testing client for humans. Painlessly test REST, GraphQL, and HTTP APIs.

## Upgrade

```powershell
choco upgrade httpie-desktop
```

## Uninstall

```powershell
choco uninstall httpie-desktop
```
