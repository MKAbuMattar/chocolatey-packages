# omnictl Chocolatey Package

## Install

```powershell
choco install omnictl
```

Chocolatey downloads the official Windows build from the [siderolabs/omni](https://github.com/siderolabs/omni/releases) releases and puts it on your PATH.

## What is omnictl?

SaaS-simple deployment of Kubernetes - on your own hardware.

## Upgrade

```powershell
choco upgrade omnictl
```

## Uninstall

```powershell
choco uninstall omnictl
```
