# Openship Chocolatey Package

## Install

```powershell
choco install openship
```

Chocolatey downloads the official 64-bit archive at install time, unpacks it into the package tools directory and shims the executables it contains. The package itself carries no binaries.

Install a specific version:

```powershell
choco install openship --version=<version>
```

## What is Openship?

Self-hosted deployment platform

## Upgrade

```powershell
choco upgrade openship
```

## Uninstall

```powershell
choco uninstall openship
```
