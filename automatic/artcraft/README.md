# ArtCraft Chocolatey Package

## What is ArtCraft?

ArtCraft is an IDE for interactive AI image and video creation. You compose in 2D,
stage scenes in 3D, and choose the models that fit your work, with visual tools for
precise, repeatable results instead of prompting alone.

ArtCraft is source-available under its own licence, not open source: it is free to
use, with limits on commercial resale and competing products. Read the licence
before relying on it.

## Usage

The package installs the ArtCraft desktop app. Start it from the Start Menu. See
[ArtCraft on getartcraft.com](https://getartcraft.com) for more.
