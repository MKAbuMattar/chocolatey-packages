# Kimi Code Chocolatey Package

## What is Kimi Code?

Kimi Code is the terminal coding agent from Moonshot AI, the company behind Kimi. It
works in your project from the command line: reading and editing code, running
commands, and carrying out multi-step tasks.

## Usage

The package installs the `kimi` command. Open a new terminal after installing so the
PATH change takes effect, then run `kimi` in a project directory. See the
[Kimi Code documentation](https://www.kimi.com/code/docs/) for sign-in and models.
