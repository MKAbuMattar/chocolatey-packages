# MiMo Code Chocolatey Package

## What is MiMo Code?

MiMo Code is a terminal-native AI coding assistant from Xiaomi MiMo. It reads and writes
code, runs commands, manages Git, and keeps a persistent memory of your project across
sessions. It is built on opencode.

## Usage

The package installs the `mimo` command. Open a new terminal after installing so the
PATH change takes effect, then run `mimo` in a project directory. See the
[MiMo Code website](https://mimo.xiaomi.com/mimocode) for setup and models.
