# DLMan Chocolatey Package

## Install

```powershell
choco install dlman
```

Chocolatey downloads the official 64-bit installer at install time and runs it silently. The package itself carries no binaries.

Install a specific version:

```powershell
choco install dlman --version=<version>
```

## What is DLMan?

Free & Fast Modern Download Manager for Windows / Mac / Linux.

## Upgrade

```powershell
choco upgrade dlman
```

## Uninstall

```powershell
choco uninstall dlman
```
