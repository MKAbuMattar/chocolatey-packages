# Touché PX5 Chocolatey Package

## What is Touché PX5?

Touché PX5 is an experimental PlayStation 5 emulator for PC, written in C#. It
originated from [SharpEmu](https://github.com/sharpemu/sharpemu) and shares much
of its code.

Upstream has published only beta builds, and none since July 2026. For an actively
developed emulator from the same lineage, see the `sharpemu` package.

It is not affiliated with Sony Interactive Entertainment. It does not provide games or
system software; use only game files you have obtained legally.

## Usage

The package installs the `touchepx5` command and a Start Menu shortcut, both of which open
Touché PX5. See the [project README](https://github.com/Techx3/TouchePX5#readme) for requirements and
game compatibility.
