# Game Cheats Manager Chocolatey Package

## Install

```powershell
choco install game-cheats-manager
```

Chocolatey downloads the official 64-bit installer at install time and runs it silently. The package itself carries no binaries.

Install a specific version:

```powershell
choco install game-cheats-manager --version=<version>
```

## What is Game Cheats Manager?

Easily download and manage single-player game cheats for your convenience.

## Upgrade

```powershell
choco upgrade game-cheats-manager
```

## Uninstall

```powershell
choco uninstall game-cheats-manager
```
