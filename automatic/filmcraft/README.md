# FilmCraft Chocolatey Package

## What is FilmCraft?

FilmCraft is an open-source video editor written in Rust, covering editing, color
and sound. It follows the Adobe Premiere Pro workflow as a clean-room
reimplementation, and runs natively.

## Usage

The package installs the FilmCraft desktop app. Start it from the Start Menu. See
[FilmCraft on getartcraft.com](https://getartcraft.com/apps/filmcraft) for more.
