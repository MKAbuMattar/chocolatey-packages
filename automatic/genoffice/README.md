# GenOffice Chocolatey Package

## Install

```powershell
choco install genoffice
```

Chocolatey downloads the official installer from the [genspark-ai/genoffice](https://github.com/genspark-ai/genoffice/releases) releases and runs it silently.

## What is GenOffice?

Free, open-source alternative to Microsoft Office with built-in AI agents , Word (.docx), Excel (.xlsx), PowerPoint (.pptx), PDF and Markdown editing for macOS, Windows & Linux.

Upstream describes it with these topics: agent, agentic, ai, ai-agent, ai-agents, ai-office, docx, excel.

## Upgrade

```powershell
choco upgrade genoffice
```

## Uninstall

```powershell
choco uninstall genoffice
```
