# FigCraft Chocolatey Package

## What is FigCraft?

FigCraft is an open-source interface design and prototyping app written in Rust. It
follows the Figma workflow as a clean-room reimplementation: frames, auto layout,
components and variants, vector networks, styles, variables and prototypes. It runs
natively and works offline.

## Usage

The package installs the FigCraft desktop app. Start it from the Start Menu. See
[FigCraft on getartcraft.com](https://getartcraft.com/apps/figcraft) for more.
