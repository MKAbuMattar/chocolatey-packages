# Dyad Chocolatey Package

## Install

```powershell
choco install dyad
```

Chocolatey downloads the official 64-bit installer at install time and runs it silently. The package itself carries no binaries.

Install a specific version:

```powershell
choco install dyad --version=<version>
```

## What is Dyad?

Local, open-source AI app builder for power users v0 / Lovable / Replit / Bolt alternative Star if you like it!.

## Upgrade

```powershell
choco upgrade dyad
```

## Uninstall

```powershell
choco uninstall dyad
```
