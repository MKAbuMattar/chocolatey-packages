# tty7 Chocolatey Package

## What is tty7?

tty7 is a terminal that outlives its window. Shells keep running after you quit the app,
agents can drive other agents, and remote machines work the same way as local ones. It is
written in pure Rust and rendered on the GPU.

## Usage

The package installs the tty7 desktop app. Start it from the Start Menu. See
[tty7.io](https://tty7.io) for more.
