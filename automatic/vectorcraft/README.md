# VectorCraft Chocolatey Package

## What is VectorCraft?

VectorCraft is an open-source vector illustration app written in Rust. It follows
the Adobe Illustrator workflow as a clean-room reimplementation, with paths,
Pathfinder operations, effects and clipping masks, and runs natively.

## Usage

The package installs the VectorCraft desktop app. Start it from the Start Menu. See
[VectorCraft on getartcraft.com](https://getartcraft.com/apps/vectorcraft) for more.
