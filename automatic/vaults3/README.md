# VaultS3 Chocolatey Package

## Install

```powershell
choco install vaults3
```

Chocolatey downloads the official Windows build from the [Kodiqa-Solutions/VaultS3](https://github.com/Kodiqa-Solutions/VaultS3/releases) releases and puts it on your PATH.

## What is VaultS3?

Lightweight, S3-compatible object storage server with built-in web dashboard. Single binary, low memory, encryption at rest.

## Upgrade

```powershell
choco upgrade vaults3
```

## Uninstall

```powershell
choco uninstall vaults3
```
