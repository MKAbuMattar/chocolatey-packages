# PilotDeck Chocolatey Package

## Install

```powershell
choco install pilotdeck
```

Chocolatey downloads the official 64-bit installer at install time and runs it silently. The package itself carries no binaries.

Install a specific version:

```powershell
choco install pilotdeck --version=<version>
```

## What is PilotDeck?

Task-oriented AI Agent productivity platform.

## Upgrade

```powershell
choco upgrade pilotdeck
```

## Uninstall

```powershell
choco uninstall pilotdeck
```
