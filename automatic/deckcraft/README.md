# DeckCraft Chocolatey Package

## What is DeckCraft?

DeckCraft is an open-source presentation app written in Rust. It follows the
Microsoft PowerPoint workflow as a clean-room reimplementation: themes, layouts,
shapes, tables, charts, transitions and animations, full-screen presenting, and
opening and saving PowerPoint files. It runs natively.

## Usage

The package installs the DeckCraft desktop app. Start it from the Start Menu. See the
[project README](https://github.com/storytold/deckcraft#readme) for more.
