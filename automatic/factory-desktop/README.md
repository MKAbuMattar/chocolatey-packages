# Factory Desktop Chocolatey Package

## What is Factory Desktop?

Factory Desktop is the desktop app for [Factory](https://factory.com), an agent-native
software development platform. You work with Droid, Factory's AI coding agent, preview
and review everything it makes, and keep each session in one native app.

Factory Desktop needs a Factory account. See [pricing](https://factory.com/pricing).

## Usage

The package installs Factory Desktop. Start it from the Start Menu and sign in.

The installer is per-user: it installs into the profile of the account that runs choco,
under `%LOCALAPPDATA%\Factory`, and updates itself from there.
