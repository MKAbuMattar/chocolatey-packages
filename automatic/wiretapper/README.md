# WireTapper Chocolatey Package

## Install

```powershell
choco install wiretapper
```

Chocolatey downloads the official Windows build from the [h9zdev/WireTapper](https://github.com/h9zdev/WireTapper/releases) releases and puts it on your PATH.
Upstream reuses one tag with no version in it, so this package is versioned by the release date instead.

## What is WireTapper?

WireTapper is a wireless OSINT tool that passively detects and maps Wi-Fi, Bluetooth, CCTV cameras, vehicles, headphones, TVs, IoT devices, and cell towers, turning nearby radio signals into clear situational intelligence.

## Upgrade

```powershell
choco upgrade wiretapper
```

## Uninstall

```powershell
choco uninstall wiretapper
```
