# tailspin Chocolatey Package

## Install

```powershell
choco install tailspin
```

Chocolatey downloads the official 64-bit archive at install time, unpacks it into the package tools directory and shims the executables it contains. The package itself carries no binaries.

Install a specific version:

```powershell
choco install tailspin --version=7.0.0
```

## What is tailspin?

A log file highlighter.

## Upgrade

```powershell
choco upgrade tailspin
```

## Uninstall

```powershell
choco uninstall tailspin
```
