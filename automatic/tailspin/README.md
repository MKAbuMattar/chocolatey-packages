# tailspin Chocolatey Package

## Install

```powershell
choco install tailspin
```

Chocolatey downloads the official Windows build from the [bensadeh/tailspin](https://github.com/bensadeh/tailspin/releases) releases and puts it on your PATH.

## What is tailspin?

A log file highlighter.

Upstream describes it with these topics: ccze, colorizer, colors, file, follow, grc, highlighter, less.

## Upgrade

```powershell
choco upgrade tailspin
```

## Uninstall

```powershell
choco uninstall tailspin
```
