# Herdr Chocolatey Package

## Install

```powershell
choco install herdr
```

Chocolatey downloads the official 64-bit archive at install time, unpacks it into the package tools directory and shims the executables it contains. The package itself carries no binaries.

Install a specific version:

```powershell
choco install herdr --version=<version>
```

## What is Herdr?

the runtime your coding agents live on

## Upgrade

```powershell
choco upgrade herdr
```

## Uninstall

```powershell
choco uninstall herdr
```
