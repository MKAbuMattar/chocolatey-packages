# MaterialCraft Chocolatey Package

## What is MaterialCraft?

MaterialCraft is an open-source, node-based procedural material designer written in
Rust. You build materials from primitives and functions in a node graph, watch them
update live in 2D and on a 3D model, and export the maps for any engine. It runs
natively.

## Usage

The package installs the MaterialCraft desktop app. Start it from the Start Menu. See
[MaterialCraft on getartcraft.com](https://getartcraft.com/apps/materialcraft) for more.
