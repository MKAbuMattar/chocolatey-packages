# LightCraft Chocolatey Package

## What is LightCraft?

LightCraft is an open-source photo library and raw developer written in Rust. It
follows the Adobe Lightroom workflow as a clean-room reimplementation, runs natively,
and can be driven end to end by AI agents over MCP.

## Usage

The package installs the LightCraft desktop app. Start it from the Start Menu. See
[LightCraft on getartcraft.com](https://getartcraft.com/apps/lightcraft) for more.
