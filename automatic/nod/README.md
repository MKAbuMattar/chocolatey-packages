# Nod Chocolatey Package

## What is Nod?

Nod is an open source personal agent from n8n with its own computer. It chases
invoices, preps your calls and cancels trials on real websites, and asks before it
acts. It runs on your machine with the model you choose, or connects to a Nod server.

## Usage

The package installs the Nod desktop app for the user running choco. It needs Windows
11 x64. A local assistant also needs WSL 2 with hardware virtualization and about 20 GB
of free disk space; Nod downloads its runtime the first time you start one. See
[nod.n8n.io](https://nod.n8n.io/) for more.
