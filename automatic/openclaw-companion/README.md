# OpenClaw Companion Chocolatey Package

## Install

```powershell
choco install openclaw-companion
```

Chocolatey downloads the official 64-bit installer at install time and runs it silently. The package itself carries no binaries.

Install a specific version:

```powershell
choco install openclaw-companion --version=<version>
```

## What is OpenClaw Companion?

Your own personal AI assistant. Any OS. Any Platform. The lobster way.

## Upgrade

```powershell
choco upgrade openclaw-companion
```

## Uninstall

```powershell
choco uninstall openclaw-companion
```
