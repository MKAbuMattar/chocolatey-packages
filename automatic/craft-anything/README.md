# Craft Anything Chocolatey Package

## What is Craft Anything?

Craft Anything studies how a website, app or game works with real inspection tools,
has a coding agent build your own version as a new project, checks the result against
the original and refines it. It is an open-source, clean-room engine written in Rust,
and needs a coding agent to do the building.

## Usage

The package installs the Craft Anything desktop app. Start it from the Start Menu. See
[Craft Anything on getartcraft.com](https://getartcraft.com/apps/craft-anything) for more.
