# Mindwalk Chocolatey Package

## Install

```powershell
choco install mindwalk
```

Chocolatey downloads the official 64-bit archive at install time, unpacks it into the package tools directory and shims the executables it contains. The package itself carries no binaries.

Install a specific version:

```powershell
choco install mindwalk --version=<version>
```

## What is Mindwalk?

A visualization tool that replays coding-agent sessions on a 3D map of your codebase.

## Upgrade

```powershell
choco upgrade mindwalk
```

## Uninstall

```powershell
choco uninstall mindwalk
```
