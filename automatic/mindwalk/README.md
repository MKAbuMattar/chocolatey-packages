# Mindwalk Chocolatey Package

## Install

```powershell
choco install mindwalk
```

Chocolatey downloads the official Windows build from the [cosmtrek/mindwalk](https://github.com/cosmtrek/mindwalk/releases) releases and puts it on your PATH.

## What is Mindwalk?

A visualization tool that replays coding-agent sessions on a 3D map of your codebase.

## Upgrade

```powershell
choco upgrade mindwalk
```

## Uninstall

```powershell
choco uninstall mindwalk
```
