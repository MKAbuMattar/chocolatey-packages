# Qwen Audio Agent Chocolatey Package

## Install

```powershell
choco install qwen-audio-agent
```

Chocolatey downloads the official installer from the [QwenAudio/qwen-audio-agent](https://github.com/QwenAudio/qwen-audio-agent/releases) releases and runs it silently.

## What is Qwen Audio Agent?

A realtime voice runtime that keeps Agents talking, working, and present. Real-time Voice Runtime for AI Agents.

Upstream describes it with these topics: acp, agent, agentic-ai, ai-coding, claude-code, codex, developer-tools, opencode.

## Upgrade

```powershell
choco upgrade qwen-audio-agent
```

## Uninstall

```powershell
choco uninstall qwen-audio-agent
```
