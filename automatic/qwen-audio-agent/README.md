# Qwen Audio Agent Chocolatey Package

## Install

```powershell
choco install qwen-audio-agent
```

Chocolatey downloads the official 64-bit installer at install time and runs it silently. The package itself carries no binaries.

Install a specific version:

```powershell
choco install qwen-audio-agent --version=<version>
```

## What is Qwen Audio Agent?

A realtime voice runtime that keeps Agents talking, working, and present. Real-time Voice Runtime for AI Agents.

## Upgrade

```powershell
choco upgrade qwen-audio-agent
```

## Uninstall

```powershell
choco uninstall qwen-audio-agent
```
