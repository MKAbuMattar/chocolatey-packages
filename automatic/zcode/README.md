# ZCode Chocolatey Package

## What is ZCode?

ZCode is Z.ai's coding agent harness, delivered as a desktop app. It is built around
Z.ai's GLM models and can be extended with your own tools.

## Usage

The package installs the ZCode desktop app. Start it from the Start Menu and sign in
with your Z.ai account. See [zcode.z.ai](https://zcode.z.ai/) for setup.
