# Archon Chocolatey Package

## What is Archon?

Archon is an open-source harness builder for AI coding. It turns AI coding work into
deterministic, repeatable workflows that coding agents run.

## Usage

The package installs the `archon` command. Open a new terminal after installing so the
PATH change takes effect. See [archon.diy](https://archon.diy) for setup.
