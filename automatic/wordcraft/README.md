# WordCraft Chocolatey Package

## What is WordCraft?

WordCraft is an open-source word processor written in Rust. It follows the
Microsoft Word workflow as a clean-room reimplementation: the ribbon, styles,
tables, track changes, references and mail merge. It reads and writes .docx
and runs natively.

## Usage

The package installs WordCraft's portable build, with a Start Menu shortcut and the
`wordcraft` and `wordcraft-cli` commands. See the
[project README](https://github.com/storytold/wordcraft#readme) for more.
