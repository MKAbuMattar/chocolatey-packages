# DesignCraft Chocolatey Package

## What is DesignCraft?

DesignCraft is an open-source page layout and publishing app written in Rust, with
threaded text frames, wrapped text and parent pages. It follows the Adobe InDesign
workflow as a clean-room reimplementation, and runs natively.

## Usage

The package installs the DesignCraft desktop app. Start it from the Start Menu. See
[DesignCraft on getartcraft.com](https://getartcraft.com/apps/designcraft) for more.
