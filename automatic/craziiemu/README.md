# CraziiEmu Chocolatey Package

## What is CraziiEmu?

CraziiEmu is an experimental PlayStation 5 compatibility layer and emulator for
Windows, written in C# and Vulkan. It runs PS5 executables directly on the host
x86-64 CPU and has a console-style dashboard. It began from
[SharpEmu](https://github.com/sharpemu/sharpemu) and has since been largely rewritten.

Every upstream release is marked alpha; expect breakage.

It is not affiliated with Sony Interactive Entertainment. It does not provide games or
system software; use only game files you have obtained legally.

## Usage

The package installs the `craziiemu` command and a Start Menu shortcut, both of which open
CraziiEmu. See the [project README](https://github.com/craze1pirate/craziiEmu#readme) for requirements and
game compatibility.
