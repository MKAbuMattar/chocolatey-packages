# Native SDK Chocolatey Package

## Install

```powershell
choco install vercel-native
```

Chocolatey downloads the official Windows build from the [vercel-labs/native](https://github.com/vercel-labs/native/releases) releases and puts it on your PATH.

## What is Native SDK?

Toolkit for building native desktop apps.

## Upgrade

```powershell
choco upgrade vercel-native
```

## Uninstall

```powershell
choco uninstall vercel-native
```
