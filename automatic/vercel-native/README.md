# Native SDK Chocolatey Package

## Install

```powershell
choco install vercel-native
```

Chocolatey downloads the official 64-bit build at install time and puts it on your PATH. The package itself carries no binaries.

Install a specific version:

```powershell
choco install vercel-native --version=0.6.3
```

## What is Native SDK?

Toolkit for building native desktop apps.

## Usage

The package installs the `native` command. Open a new terminal after installing so the PATH change takes effect, then see the [Native SDK documentation](https://native-sdk.dev) for the available options.

## Upgrade

```powershell
choco upgrade vercel-native
```

## Uninstall

```powershell
choco uninstall vercel-native
```
