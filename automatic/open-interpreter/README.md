# Open Interpreter Chocolatey Package

## Install

```powershell
choco install open-interpreter
```

Chocolatey downloads the official Windows build from the [openinterpreter/openinterpreter](https://github.com/openinterpreter/openinterpreter/releases) releases and puts it on your PATH.
The archive bundles ripgrep and several internal helpers. Only the `interpreter` command is put on your PATH so nothing you already have is shadowed.

## What is Open Interpreter?

A coding agent for open models like Kimi K3.

Upstream describes it with these topics: acp, coding-agent, deepseek, kimi, qwen, rust.

## Upgrade

```powershell
choco upgrade open-interpreter
```

## Uninstall

```powershell
choco uninstall open-interpreter
```
